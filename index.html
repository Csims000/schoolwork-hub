One-time cloud setup

Connect a free Supabase project. These are public project settings; never enter a service-role/secret key here.

After saving the connection, run the SQL setup shown below in your Supabase project's SQL Editor. Then create your account here.

Database SQL (run once in Supabase → SQL Editor) 
create table if not exists public.schoolwork_data (
  user_id uuid primary key references auth.users(id) on delete cascade,
  content jsonb not null default '{"classes":[],"assignments":[],"notes":[],"projects":[]}'::jsonb,
  avatar text,
  updated_at timestamptz not null default now()
);
alter table public.schoolwork_data enable row level security;
revoke all on public.schoolwork_data from anon;
grant select, insert, update, delete on public.schoolwork_data to authenticated;
drop policy if exists "Users can read own schoolwork" on public.schoolwork_data;
drop policy if exists "Users can insert own schoolwork" on public.schoolwork_data;
drop policy if exists "Users can update own schoolwork" on public.schoolwork_data;
drop policy if exists "Users can delete own schoolwork" on public.schoolwork_data;
create policy "Users can read own schoolwork" on public.schoolwork_data for select to authenticated using ((select auth.uid()) = user_id);
create policy "Users can insert own schoolwork" on public.schoolwork_data for insert to authenticated with check ((select auth.uid()) = user_id);
create policy "Users can update own schoolwork" on public.schoolwork_data for update to authenticated using ((select auth.uid()) = user_id) with check ((select auth.uid()) = user_id);
create policy "Users can delete own schoolwork" on public.schoolwork_data for delete to authenticated using ((select auth.uid()) = user_id);
